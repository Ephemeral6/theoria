# cold-start-a3 — the two books, carried to a second level

A3 tests [Theoria.md](../Theoria.md)'s **Claim C3** offline:

> C3 迁移：携两本书跨关，第二关边际成本 ⟨≪⟩（条件性，视关卡共享机制程度，Phase 1 核实）

and it tests it in the strict sense §1.10a fixes, which is the only sense that
can be checked:

> 说明书是 **domain**(跨关不变)，关卡布局是 **problem**(逐关实例) ——
> PDDL 本就强制这么切，C3"迁移"的严格含义就是 **domain 带得走**。

Zero API calls, zero network, zero contact with the sealed pile.  The world is
self-built; its truth is a Python function the pipeline never imports.

## The result in one paragraph

A 9×9 world with four mechanisms — push, a toggle Switch driving a Door, a
two-way portal pair, and a goal — laid out as **two levels sharing no placed
cell**.  Level 1 is cold-started: 333 frames of systematic sweep, 41 candidates
adjudicated by hand into a 20-rule domain and a playbook, certify green on both
layers, Lean signing an axiom-free invariant, plan SAT in 15, win.  Then the
**same two book files** are carried to level 2, which is rebuilt from **one
frame**, and the pipeline plans and wins with **no engine run, no candidate
read, no theorize round and no clause written**.  The generated predictors for
the two levels differ *only* in the landmark table, the board, the goal cell
and the initial placements — every guard and every effect is byte-identical.

## The bill

Generated by `a3pipeline/bill.py` into
[`artifacts/bill_table.md`](artifacts/bill_table.md); these numbers are read
off the meters, not typed.

The like-for-like column is the one to quote: **the same level, with and
without the books.**  Same supplied constants, same certify, same planner.

| meter line | L1 cold start | L2 from scratch | **L2 carrying the books** |
|---|---|---|---|
| world frames | 348 | 347 | **11** |
| world actions | 347 | 346 | **10** |
| engine stages | 1 | 1 | **0** |
| candidates adjudicated | 41 | 35 | **0** |
| theorize rounds | 1 | 5 | **0** |
| DSL clauses written | 23 | 33 | **0** |
| compile / certify / plan runs | 1 / 3 / 1 | 1 / 3 / 1 | 1 / 3 / 1 |

The bottom row is the honest part: carrying a domain does not make a level
cheaper to compile or a plan cheaper to check, and it should not.  What
collapses is everything upstream of the manual.

**Cost to first plan** — the snapshot at the moment a plan first existed, which
is the front-loading measure C2 is about:

| | L1 cold start | **L2 carrying the books** |
|---|---|---|
| frames | 333 | **1** |
| actions | **332** | **0** |

The transfer arm reaches a plan having spent **zero actions** — on a live game
that is the quota line, and it is the number C3 is really about.

## The books are not a private convention

The obvious objection is that whoever carried the books to level 2 wrote them
for level 1 and already knew the answer.  So level 2 was *also* theorized
**blind**, by a worker with no access to `theory/domain.dsl`, the theorize log,
the world's source or the referee's copy.  Every one of level 1's twenty
clauses turns up in the blind manual; the invariants and the `semantics:`
section match exactly; both arms independently rejected every no-op rule and
every guard containing a coordinate.  Textually the two agreed on **nothing** —
different object names, different landmark names, lifted rather than ground
rules — which is itself a measurement of how much of a manual is convention.

The blind arm's manual also scores **252/252** against the referee, and so does
the carried one.  Two manuals, disjoint evidence, same level, both exactly
right.  `A3_REPORT.md` §4, including an incident: the blind was partially
broken by us in round 3, and the report says exactly what that does and does
not contaminate.

## The safety valve

Carrying a domain is only safe if a *wrong* carried domain is caught.  Two
negative controls, both rendering **byte-identical first frames** to level 2 —
the edit is in the transition function, not in the pixels:

| | `l2-oneway` (leg deleted, level unsolvable) | `l2-rewired` (leg lands elsewhere, level still solvable) |
|---|---|---|
| static certify, frame 0 | GREEN — the board cannot show it | GREEN |
| plan | SAT | SAT |
| replay certify, after acting | **RED** | **RED** |
| claimed a win | **no** | **no** |

The free half of the valve is blind to a transition-function edit and the paid
half catches both.  That boundary is the honest statement of what carrying a
domain costs in risk.

## Run it

```bash
cd cold-start-a3
python run_all.py                    # every arm, in order
python -m pytest                     # the suite
python -m tools.verify_readonly      # hash the other tracks, run, hash again
python -m tools.archive_run P-17     # runs/ archive with provenance
```

Artefacts are byte-reproducible for a fixed seed — there is no seed, because
there is no randomness; determinism here is structural.

## What is reused, and where reuse stops

A3 writes **no engine and no generator**.  The engines are `engine-rig`'s, the
parser is the frozen v0.2 contract's, and the four compile backends and the
cheap certify layer are `cold-start-a0`'s, imported unmodified.  A3 supplies a
world, a meter, a problem builder and the drivers that join them.

`cold-start-a2` is deliberately **not** on the import path: it is a sibling
experiment, not a library.  Where A2 wrote a workaround A3 also needs, A3
re-derives it and credits it — see `_bootstrap.py`.

Reuse is read-only.  `python -m tools.verify_readonly` hashes every file under
`cold-start-a0`, `engine-rig`, `theory-compiler` and `CONTRACTS`, runs the whole
pipeline, and hashes again.

## Four findings about the reused code

All four are in [`DECISIONS.md`](DECISIONS.md) and on `PARTNER_SYNC.md`; none
was fixed in place, because those are other tracks' directories.

* **D-A3-003 — `mdl_segmenter` loses the mover when it lands on a marked cell.**
  Measured, not predicted: the mover's track went missing in 19 of 326 frames
  and the miner proposed appear/vanish rules instead of a jump.  The run is
  kept at `artifacts/finding_d_a3_003/`.  Third segmentation gap in this family.
* **D-A3-004 — three of the four co-derived forms do not honour the
  domain/problem split.**  With no `goal:` section — the only kind of domain
  that *can* travel — the Python backend silently emits `is_goal: return False`.
  A3 supplies a binder.
* **D-A3-005 — the PDDL backend cannot encode more than one portal.**  One
  global `(portal-exit ?c)` predicate, emitted only for a landmark literally
  named `portal_exit`: with two portals the planner returns a confident **UNSAT
  for a correct manual**, and even patched naively the two jump families would
  share a destination set, which is unsound.
* **D-A3-007 — the Lean invariant helper is keyed on the object's *name*.**  An
  object called `Switch` instead of `Button` gets `I := true`, all theorems
  green, empty axiom list, and nothing proved.  The vacuous artefact is kept
  next to the real one.

## What A3 does not show

Levels of one game, not different games; 62 and 63 reachable states, not scale;
100 % sweep coverage, which no live game affords; and a bill measured in
structure — frames, actions, clauses, rounds — not in tokens or dollars.  The
bounds are stated in full in [`A3_REPORT.md`](A3_REPORT.md) §6.
