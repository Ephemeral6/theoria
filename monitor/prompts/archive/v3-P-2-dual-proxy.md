# P-2 · 双代理：把「封闭系统」从纪律变成构造

领地：新建顶层 `proxy/`。其余只读（`baseline-arms/harness/` 有可参考的客户端与账本）；`PARTNER_SYNC.md` 只追加；提交只 add 自己领地。

目标：Phase 1 的记录面。环境代理（三臂只改 base URL；`ARC_API_KEY` 只在代理内注入；全量入账；**封存堆护栏在代理层强制拒绝**，数据源 `arc-recon/data/piles.json`）；模型代理（usage 逐字入账、价目表版本化）；统一账本格式（`env_step`/`model_call`——先写 `LEDGER_FORMAT.md` 再写码，它是三臂与电池的共用格式）；密封测试与分数对账器；变体注入层起架（包裹合法集，每变体带构造性依据）。
