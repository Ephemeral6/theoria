# Phase-3 迭代先例简报（web 调研，2026-07-31）

调研员报告全文的裁剪版（逐句已滤净封存局信息，只保留开发堆局名）。
原始出处见文末链接。

## 领域现状：与本框架同形，差异全在调度层

- **OPINE-World**（arXiv 2607.01531）：无训练最好成绩。反例触发式综合
  （短暂缓冲几个反例再重写 + 停滞守卫）、本体误差引导戳探（效果签名
  的 Dirichlet 后验熵按对象排队）、综合器每批反例重开上下文（防固执）、
  规划器在关卡未清前不放行。其 g50t 全 7 关通关，L1 = 90 动作——
  **g50t 关卡 1 的动作成本不高，我们的 $12-15 是被 theorize 调用吃掉的。**
- **baseline1**（arXiv 2605.05138）：停滞与 GAME_OVER 后触发"合并特例"
  重构（MDL 代理）；点名失败模式**过早承诺**（在错模型里持续精修）。
- **消融**（arXiv 2607.15439）：四嵌套变体中**精确重放验证位列第一**
  （全部 4 组设置）；无验证的可执行模型可输给纯文本 agent。
  验证是承重件——与本框架 certify 的立场一致。

## 十条 one-change 候选（完整表见调研输出，按杠杆排序的前三）

1. **theorize 延迟批处理**：意外入缓冲，攒 K 个或 T 动作一次裁决。
   预期：每关 opus 调用 ↓≥40%，$/关同降。类：修订抖动/调度失误。
2. **梯度模型阶梯**：sonnet/haiku 起草 N 个修订候选 → 引擎按重放
   **机械拒绝**（只拒不收，分工三律无损）→ opus 只裁幸存者。
   预期：$/theorize 从 $1.7-1.9 降到 <$0.8。类：调度失误。
3. **η-戳探**：引擎侧效果签名熵表引导 probe 排队，零 LLM 成本，
   顺带补上"意外趋零"的仪表本体。类：戳探设计差。

其余：批量 N 假设/调用（Hypothesis Search 形状）、重放门前置于
Lean、settled 语义、意外签名分诊、theorize 上下文重开 + 泛化批评者、
平台期压缩重构。

## 禁走（构造性约束，别花周期）

测试期改权重（证据还站在我们这边：程序派 78.4 > 预训练过评测局的
权重派 63.2）；引擎终审（我们的引擎只出候选）；玩法书存字面解
（对方的赢路缓存不可抄）；动作洪泛（RHAE 平方惩罚 + 5× 截断）；
玩中查攻略（即 INC-BA-001 的暴露类）。
