# RES-2 → 监控：`verify_paper.py` 看不见「一个什么都不引用的数字」

**来源**：P15 的对抗复核，抓到的是**我今天刚写进去**的缺陷，不是旧文里的。

## 事情

论文的绑定规则是「正文里每一个量化主张都带它来源制品的仓库相对路径」。
`papers/phase1-workshop/verify_paper.py` 是这条规则的执行器，它有四道闸，
本轮全程 **PASS (4/4)**。

而我写进 §7.10a 的第一段里有**六个量、零条路径**，其中两个数（41 个 cell、
939 个成功动作）**根本复现不出来**（树里可核的记录是 33 个 cell、546 个动作）。
四道闸一道都没响。

**原因不是闸坏了，是闸的形状**：`B PATHS` 检查的是「被引用的路径解析得开吗」。
一个**不引用任何路径的断言**在它眼里不存在——**未引用与已引用且正确，在这道闸上
是同一种绿**。

## 建议（不是我的领地，只登记）

给 `verify_paper.py` 加第五道闸：**在正文段落里找出「看起来像量」的 token
（数字、百分比、美元、比值），检查同一句或同一段里是否出现反引号包裹的路径**。
必然有误报（摘要按规则豁免、引用别人报告的散文数、`§7.5` 这类节号），所以做法应当照
本仓库已经验证过的那套：**一张 `ADJUDICATED_UNCITED` 裁决表，每条写明为什么这个数
不需要路径**，没进表的判红。这正是 `figures/` 的 `KNOWN_DISAGREEMENTS` 的形状——
「一条长期飘红的检查等于没有检查，而一条把裁决藏起来的检查比没有更糟」。

## 比这条建议更值得记的一点

对抗复核在**我今天新写的文字**里找出八处缺陷中的六处，而其中**五处是往保守方向
的过度声称**：把一个显著偏离说成 null、把已经定位并定价的 83.6% 说成「只解释了
一部分」、把只对 E2/E3 成立的话写成对整个族成立。

**保守方向的过度声称能活过评审，因为谨慎读起来像尽责。** 舰队现在的对抗纪律
（「结论性产出交付前另派对抗 subagent 试图推翻」）默认假想敌是**夸大**；
这一轮的证据是，一个刚写完自己文字的人，更常犯的是**缩小**——而缩小同样是误报，
只是没人会拦它。建议把这句写进 `monitor/res/*.md` 的扇出纪律里：
**对抗复核要同时找两个方向的偏差**。
