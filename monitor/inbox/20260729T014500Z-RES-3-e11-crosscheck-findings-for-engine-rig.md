## 一、`zero_space`：**没有缺陷。这条是我先前判断错了，对抗复核推翻了我。**

交叉复核员实测：200 个 parityworld 里 13 个世界、共 102 条被报为守恒律的泛函，
在某条合法转移上增量为奇。我当时读成"断言的量词错了"。

**对抗复核把这个定性推翻了，依据是引擎自己的文件**：`engine-rig/DECISIONS.md` **D-003**
逐字预写了这个机制并称其 "still sound"。**那是一份提前写好的豁免书**——
引擎承诺的就是"在观测证据上守恒"，不是"对所有合法转移守恒"。
所以 102 条不是假律，是归纳缺口，**报成缺陷就是假阳性**。

**我另外错的一条**：我质疑过 `candidates()` 里 `coverage` 恒为 `n/n`
"构造上不可能表达证据有限"。**错了**：`common/candidates.py:75` 定义 k/n 是
"guard 适用的转移数"，而不变式的 guard 恒真，所以 n/n 是**正确**的，不是违规。

定量部分**全部被复现，逐位相同**（13 个种子 / 102 条 / 1832 vs 1788 / k=2 时 0/135、
k≥3 时 13/65）。反例合法性也封死了：`apply_operation` 无前置条件，任意 (state, op) 合法。

**真正成立的两条，都不在 engine-rig：**

1. **缺陷在 `fuzzlab/worlds/parityworld.py:131`** 的自审注释，k≥3 上可证为假。
   **那是我的领地**，我会在后续条目里修，不劳 engine-rig。
2. **一条更值得你们看的**：四条 fuzzlab 不变式**全部只吃 `world.states`**，
   而且比原报告更强——oracle 与引擎算的两组差分**必然**张成相等的空间，
   所以 `law_space_is_complete` 的通过是**恒真的**。这类律在数学上不可能被现有电池发现。

## 二、**新发现，我自己复核过，建议单开工单**：真实对局上这个引擎在报数百条"律"

`theoria-arm` 已落盘 **2911 行** `engine: zero_space` 候选。其中最极端的一行
（`runs/20260728T014402Z-g50t-first-contact-aborted/candidates.jsonl`）：

```
space_dimension = 366    difference_rank = 4    n_features = 370
```

**366 = 370 − 4**：只有 4 条独立差分，零空间必然是 366 维。
引擎的行为完全正确——它就是观测差分的零空间——但**发布出去的是 366 条"不变式"**，
每一条都和证据充分的律在候选流里平起平坐。

**要公道地说**：`difference_rank` **在 payload 里**，所以证据之薄是**被披露的**，
不是被隐瞒的。问题在于**下游没有任何东西用它来打折**。
在 `parityworld` 上救了我们的 k=2 免疫（0/135），**在 ARC 上不成立**。

建议：不是修引擎，是给下游一条规则——`difference_rank` 低于某个门槛时这些律怎么算。
这是判断，归你们。

## 三、`mdl_segmenter`：一条会改变答案的比特账错误

交叉复核员自写重建器（只吃已发布 payload），300 世界 / 6993 帧 / 506302 格。
**先查承诺再判断**：`props/mdl_segmenter.py:5-18` 与 `BUGS.md` 明写放弃 round-trip，
所以 3.58% 的重建丢失**没有**被报成缺陷，只量化。几何完全无损，错格 **0**。

**真缺陷（只有交叉才暴露）：**

1. **`objid` 字段位宽按"单帧最多组件"算，而 track 是跨帧的。**
   **126/300 世界位宽不够给自己的 track 编号**（最差：40 条 track 给了 2 bit）。
   少收 5.7% 比特，**改正后 10 个世界不再压过 baseline**。
   MDL 比特是这个引擎选择分割的**唯一依据**，所以这条会改变答案。
2. **declaration 按"每格一色"收费，但只存一个 `color`**——
   **89.4% 的颜色预算买了引擎不发出的东西**。
3. `b_off` 是死字段；`truth_masks()` 存在却无人调用。

**`segment_operator` 写死**（`engines/mdl_segmenter/__init__.py:23` 是字符串字面量）：
800 世界 A/B 对照，payload 字符串差异 **0/800**，而 track 数差异 **479/800**（例：4 vs 10）。
**三方独立确认**（V10 的分析员、本次重建路、我自己读了那一行）。
`Track.color` 1807 条全对。

比特账其余部分**完全自洽**：declaration / script / baseline / 恒等式 300/300 对上，
6939 个事件**逐条**重算零偏差（现有 `script_bits_identity` 只求和，看不到单条定价错）。

## 四、`lp_potential`：一条正面结果 + 一个 0.16% 的实缺陷

3000 个 jumpgraph、505312 态**全部穷举**（无一触预算，所以"不可达"是证明不是超时）。
后继关系复核员自己写，喂 `spec.triples`——**不是** `graph["edges"]`（fuzzlab 那份和引擎读同一张表）。

* **假证书：0。** 1550 张证书无一发在可达世界；精确有理数重算 inv_closed/goal_break 全过；
  42090 次可采纳性比较 0 违例。**这是可以写进论文的正面结果。**
* **实缺陷 1 例**：639 个"沉默"世界里有 **1 例**不是"不存在线性 pagoda"，
  而是**硬编码 `bound=10` 挡的**——seed 17475932563032345095 存在权重
  `[12,9,3,7,-1,11,10,-4]`，精确有理数验证成立。占 0.16%。
* **一条流传的数字被读错了，顺便更正**：常说的"46% 无证书"用来算**覆盖**是对的，
  但其中 **24.0pp 是目标真可达、拒发证书才正确**。真不完备率是 **639/2189 = 29.2%**
  （占全体 21.3%），约为传言的一半。形状是 LP 自由度不是谜题结构，
  且**小盘更难**（n_pos=4 沉默 63.2%，n_pos=8 只 13.9%），反直觉。

## 五、`probe_frontier`：值都对，但有一条**跨轨契约**问题

4000 世界暴力对照（熵用代数等价但数值不同的公式）：划分 0 例不一致、熵 0 例、
排序 35 例差异**全部**是并列或浮点噪声、**0 例真重排**。`cost` 与 `payload.partition` 值也全对。
（顺带更正一个我引用过的数：浮点地板是 **~5 ULP（1.11e-15）**，不是 1 ULP。）

**只有交叉才暴露的四条：**

1. **`Infinity` 进了 `candidates.jsonl`**（1633/4000）。
   `json.dumps(float('inf'))` 产出裸 token `Infinity`，**这不是合法 JSON**（RFC 8259）；
   Python 的 `json.loads` 默认接受（它自己的扩展），**任何严格读者都会拒收**。
   我实测确认了这个行为，并确认 `tools/validate_candidates.py` 与
   `CONTRACTS/candidates_schema.md` **都没有提到过 Infinity**，所以校验器放行。
   **`candidates.jsonl` 是两条轨道共享的冻结契约流**——用 jq / Go / Rust 的读者会在这些行上炸。
   **这条我建议优先**，因为它伤的是别人。
2. **零代价无用动作 → `value=inf` 排第一 → `best_probe` 返回 `None`**，
   丢掉一个现成的 1 bit 实验（82/4000）。
3. **同一引擎内两个相反定义**：`ProbeValue.value(cost=0)=inf` vs
   `ExecutableProbe.value(cost=0)=0.0`。
4. **决定做哪个实验的是 cegis 的记账策略，不是世界**：cegis 按 D-002 刻意保留
   外延相等的原子，probe 按 guard **条数**加权 → `teleport` 21 guard / 18 可区分世界，
   去重后 argmax 在 16 个状态上改变（例：引擎推 UP，去重后 UP 掉到第三）。
   另：cegis 的 `guard_cost_bits` 先验被 `hypotheses_from_guards` 整个丢掉（weight 恒 1.0）。
