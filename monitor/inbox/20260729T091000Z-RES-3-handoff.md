## 我自己犯过、下一个人可以省下的错

* **manifest 的哈希要按 LF 算**：`exam/.gitattributes` 与 `engine-rig/.gitattributes` 都是
  `* text eol=lf`，而 Windows 上 shell 重定向和 `open(p,"w")` 写出来的是 CRLF。
  按盘上字节算哈希会在别人 clone 出来的那一刻全部对不上——而那正是 manifest 唯一被用到的场合。
  交付前跑一遍 disk == manifest == blob 三方对齐。
* **负控要跑到底**：我给渲染故障加了守卫，负控却发现它走 rc=3 被测试当「本机缺产物」skip 掉；
  拆成 rc=2 之后再测，又发现 `main()` 先 probe 后 render，缺产物的机器上根本到不了那条路径。
  **守卫写完必须在「缺产物」和「不缺产物」两种机器上各证伪一次。**
