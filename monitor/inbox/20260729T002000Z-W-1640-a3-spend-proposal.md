## 但活是干完的，卡在授权而不是卡在实现

在花掉第一分钱之前，我找到并修好了三个会让这场战役白烧钱的缺陷。三个都在
`theoria-arm`（我的领地），都有回归测试，且**每一条都在 `verify.sh` 里被重新
打断证明测试会变红**：

1. **每一次 model 调用都会在付完钱之后崩掉。** `modelcall.py` 把
   `beat/label/transport/proxied/proxy_gap` 当顶层字段传给 `RunLedger.model_call`，
   而 `canon.MODEL_CALL_FIELDS` 是十个名字的**封闭集**。抛点在
   `cli_cost_usd` 已累加、`binding.record_model_call` 已结算**之后**——
   也就是钱付了、账记了，然后写记录时死。第一次 theorize 就会中，之后每次都中。
   `inner/loop.py` 把它吞成「desk 失败」，所以**一场 $200 的战役会产出零本说明书**。
   没被发现是因为 `--mock` 设 `offline=True` 直接跳过 theorize，全仓没有一个测试
   驱动过一次*完成的* model 调用；而所有 desk 测试用的 `FakeRun.model_call`
   只把 kwargs 追加进列表，什么都不校验。
2. **战役的美元记账是死的。** `campaign.py` 读 `desk["cost_usd"]`，而
   `ModelDesk.summary()` 从来只发 `cli_cost_usd`。每条腿都记 $0.00，
   `$60/局` 与 `$200/战役` 的天花板**永远不会触发**。
3. **游戏 ID 靠运气没进提示词，不是靠构造。** Theoria.md:353 是硬规

   对抗性探针证明这不够：引擎抛异常 → `world/adapt.py` 记 traceback →
   `evidence_brief` 把报告塞进提示词 → `OSError` 消息带着它失败的那个路径 →
   而 run slug 里嵌着 game stem。强制一次候选写入失败，**一条 20,975 字符的真实
   提示词里出现了 6 次 `g50t`**。同形状的另外两条通道（`compile_all` 的写错误、
   Lean 诊断里的绝对路径经 `proof_failure` payload 进下一轮）现在是活的但休眠。
