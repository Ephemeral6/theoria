# C6 · 世界工厂加 mutate：解锁考卷另外三型

W-1540 报告 V2 只交付了四题型里的一型，另外三型卡在**仓库里不存在的东西**上：
考卷需要「同一世界的受控变体对」（改一条规则 → 真值已知的新世界），worldgen
目前只会造独立世界，不会造变体对。

做 `worldgen/mutate.py`：给定一个已出厂世界 + 一条规则级编辑（禁一个动作、
改一条守卫、把可逆机关改成不可逆、移动一个 portal 出口），产出新世界 + 新真值 +
**编辑的机器可读描述**（考卷判卷要用它算「检测延迟/修复成本/连带作废」）。
每种编辑至少两个实例，出厂检验同 C1（抽样跑 cold-start-a0 流水线）。
产物直接供 exam 的改规则适应题与判决题使用（接口写 RUN_STATE，不改 exam 目录）。
