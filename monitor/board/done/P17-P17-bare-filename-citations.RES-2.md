# P17-P17-bare-filename-citations · B1: 论文自己的引用规则（仓库相对路径）没有执行器，裸文件名是两道闸共有的洞

P16 关掉了「一个数不引任何路径」这一类。它同时暴露了下一类，而且是**两道闸共有的**盲区：**裸文件名**。

- 闸 B（路径可解析）**按设计跳过不含 `/` 的 token**——它只检查带路径的引用；
- 闸 E（每个量化块要有出处）接受裸文件名，只要该 basename 在树里**任意位置**存在。

于是 `` `STATUS.md` `` 是一条**两道闸都不真正检查**的引用。P16 加的 `_basename_exists`
是「最弱的、还能让编造者付出代价的检查」，它挡住了不存在的文件名，**挡不住有歧义的**。
`OPEN_ITEMS.md` B1 已经量过这个洞：**22 个不同路径、30 处出现**，其中 9 个在树里
有 6–24 个真实候选（`STATUS.md` → 8 个文件、`THEORIZE_LOG.md` → 6、`theory.dsl` → 13、
`raw_trace.jsonl` → 24）。读者拿着论文无法核对任何一处。

这不是排版问题：论文自己写下的规则是「正文每一个量化主张都带**仓库相对路径**」，
而这 30 处是该规则的公开违例，且**没有执行器**——和 P16 之前的情况一模一样。

做五件：

1. **枚举**。写一个可复跑的清单：每个裸文件名引用的位置（section:line）、它在树里的
   全部候选、以及候选数。这是 B1 那两个数（22 / 30）的可核形式，B1 现在只是散文。
2. **消歧**。逐条判定它指的是哪个文件——**证据从上下文来**（同段其它引用、被引的行号、
   被引内容能否在候选里 grep 到）。**不能凭「最像的那个」猜**；判不出的记成判不出。
3. **改**。判得出的换成仓库相对路径。判不出的**不要瞎填**：要么改写句子让它不再依赖
   那处引用，要么明写「该制品在树里有 N 个同名候选，本文无法指定」——诚实的空白
   胜过一条指错的路径。
4. **加闸 F**（或扩 B）：裸文件名在正文中判红，除非进裁决表。裁决表照 P16 的形状——
   逐条写明理由，理由每次运行都打印。**注意**：`.toolchain/`（B2，按设计 gitignore）
   和 `figures/` 那批已有裁决，不要重复判它们。
5. **顺手关掉 B3 / B4**（各一处，已定位）：`PROVENANCE.md` 把
   `theory-compiler/src/certificate.py` 写错，真路径是
   `theory-compiler/src/theory_compiler/certificate.py`；以及它把分割位归给
   `THEORIZE_LOG.md` O-03，实际在 O-01。**两处都要先自己核一遍再改**——
   B3/B4 本身是审计散文，未必对。

**交付前派对抗 subagent**：任务是**构造一条能骗过新闸的引用**——比如指向一个存在但
与该数无关的路径、用相对路径写法绕开、把歧义文件名塞进表格行或脚注。骗过了就说明判据要改。
另外让它复核第 2 步的每一条消歧：**它推不翻才算数**。

**不要做错的一条**：闸 F 不是要求消灭裸文件名，是要求**正文里承载量化主张的**引用可定位。
`REVIEW.md` / `CITECHECK.md` 这类论文自己的伴随文档在散文里被提名字，不是出处引用。
把它们判红会让闸变成噪音而被关掉——P16 已经踩过一次这个形状。
