# S4-S4-E1-HOLES · 终点一的三个空洞：没有 ⟨X_clean⟩、没有不可结论版、而闸门在锁死刚被判废的硬下限

E-WORDING（cycle 38）关掉了三主终点的 13 处措辞分歧，但对抗性复核留下三条红的没修，全部集中在**终点一**，而 C1 是主骨——机械规程第 7 步让论文标题与摘要压在它上面。逐条：

(1) **没有 ⟨X_clean⟩。** ⟨X⟩ 一个符号同时要满足 claim 层 14/19 与 clean 层 10/12，而 0.737 ≠ 0.833；硬下限那一对同理（0.526 vs 0.583）。后果落在逐字文本上：C1 成立版给 clean 层**没有过线**，只有『两层一致』这个未定义谓词，再叠上 §1.2『分歧时以弱者为准』，整个 clean 层裁决就是看到数字之后的判断。终点二在 §2.2.1 已经铸了 ⟨m_clean⟩，终点一没铸。**做法**：铸 ⟨X_clean⟩，两份文件同批，并让 stage 16 的 E1/tier 要求它。

(2) **C1 没有不可结论版，而给出的理由可能是非推论。** 我写的是『U3 是单样本比率、没有剔除，所以没有剔太多这种结局』。但『没有剔除机制』不等于『不会没有信息量』：§4.1.0 自己的理由是高死亡率下活下来的格是被基础设施而非随机性选出来的，这对 U3 一样成立。按本文件自己的悲观 q，⟨X⟩=14 时功效只有 **0.3739**——于是最可能发生的事是基础设施死亡被逐字发表成 C1 不成立版那句『一个显式声明的世界理论在野外游戏上未能稳定证得动，是本工作的主结论』。**把没测到写成测到了没差别**，正是 §4.1.0 说本文件存在就是为了防的事。**做法**：要么给 C1 写一版不可结论版（判据不能是剔除率，得是别的，比如非空转检查跑不动的局数占比），要么把『为什么 U3 不需要它』论证到能扛住上面这一段。

(3) **stage 16 反向锁死了 §1.3 的裁定。** §1.3 刚裁定硬下限**不是过线**、只是 ⟨X⟩ 的取值下界，裁决时引用它是 incident。而 stage 16 的 IDENT 探针 E1/hard / E1/hardc **硬性要求** `硬下限10` 与 `硬下限7` 同时出现在两份文件里——于是『把硬下限从文件里删掉』这个最干净的收口**会让闸门变红**。闸门在强制维持一个刚被判定不许当过线的数字的显著性。**做法**：先定硬下限留不留（留则探针改为要求它带着『不是过线』的限定语；不留则删探针并删数）。

三条是一件事：**终点一的过线与结局空间没有被写完**。服务的论文槽位是 C1 主骨的裁决段。全部材料在 freeze/runs/20260729T2145Z-E-WORDING/RUN_STATE.md §3.2 第 1–3 条。
