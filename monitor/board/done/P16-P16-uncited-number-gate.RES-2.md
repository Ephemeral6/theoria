# P16-P16-uncited-number-gate · verify_paper 加第五道闸：抓「不引用任何路径的数字」

P15 的对抗复核抓到一处缺陷，抓的是**当轮刚写进去的文字**：新增 §7.10a 第一段有**六个量、零条制品路径**，其中两个数复现不出来（写 41 个 cell / 939 个成功动作，树里可核的是 33 / 546）。而 `papers/phase1-workshop/verify_paper.py` 全程 **PASS (4/4)**。

**闸没坏，是闸的形状不对。** `B PATHS` 检查的是「被引用的路径解析得开吗」；一个**不引用任何路径的断言**在它眼里不存在——**未引用**与**已引用且正确**在这道闸上是同一种绿。而论文的绑定规则恰恰是「正文每一个量化主张都带路径」，也就是说：**论文最核心的那条纪律，目前没有执行器**。

做四件：

1. 给 `verify_paper.py` 加第五道闸：扫 `sections/*.md` 正文段落里「看起来像量」的 token（整数、小数、百分比、美元、比值、n=…），检查同一句或同一段内是否出现反引号包裹的仓库相对路径。
2. **必然有误报，按本仓库验证过的形状处理**：一张 `ADJUDICATED_UNCITED` 裁决表，每条写明这个数为什么不需要路径（摘要按 `00_abstract.md` 自述豁免；节号 §7.5；引用他人报告散文数且已自述为「报告的说法」；构造常数如 0.25）。**没进表的判红。** 参照 `figures/` 的 `KNOWN_DISAGREEMENTS`——「一条长期飘红的检查等于没有检查，一条把裁决藏起来的检查比没有更糟」。
3. 先在**当前正文上**跑一遍，把它抓到的每一条分诊：真缺路径 / 该进裁决表 / 误报。真缺路径的**当场补上**。
4. 交付前派对抗 subagent：它的任务是**构造一个能骗过这道闸的句子**——比如把数字写成英文单词、把路径放在相邻段落、引用一个存在但与该数无关的路径。骗过了就说明闸的判据要改。

**注意一条不要做错的**：这道闸不是要求每个数字都带路径，是要求**正文里的量化主张**带路径。摘要是论文自己声明的唯一豁免，把摘要判红会让整道闸变成噪音而被关掉。

服务 WP9。零 API、零封存堆接触。
