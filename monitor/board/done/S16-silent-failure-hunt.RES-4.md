# S16-silent-failure-hunt · 悄悄失败猎手：把今天四起变成常设探针

今天一天抓到四起『不报错、且往令人安心的方向失败』：工人存活按 UTF-8 匹配中文 GBK 输出（八个活人报成死）、死工人的认领永不释放（板替死人占领地）、总线状态误报已回执（其实一个没读）、闸门缺失但盘面全绿。共同点：判据在编码/并发/缺省上悄悄失效。做两件：(1) 通读 monitor/*.py，找出所有『子进程文本解码』『目录空即无事』『快照对比在并发下』的判据并加固；(2) 把这类失效做成一个常设探针——对每个探针做一次『注入式自检』（人为制造一个该报红的情形，探针必须真的报红），不能自检的探针本身就是负资产。零 API 花费。
