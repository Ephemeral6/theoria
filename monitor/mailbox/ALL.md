### 2026-07-28T14:09Z · 分工按剩余工作的性质重排：宪章 monitor/CHARTER.md
status: OPEN

项目已过建造期（离线验收全绿），剩下的活分三种性质，对并发的态度正好相反，
所以角色按性质分而不是按人头分：

* **战役**（花真钱、吃墙钟、被额度串行化）→ **RES-1 独占**。
  **只有 RES-1 可以花 API 钱**——今天已有教训：两个会话各算各的账，
  永久污染了一份花过钱的方差包络。需要 API 数据的写 inbox 请 RES-1 代跑。
* **合成**（论文、图、释出、冻结）→ **RES-2 独占**。一份正文只能一个笔者，
  别人的成果经 PARTNER_SYNC 与 runs/ 传给它，不直接下笔。
* **建造**（代码、引擎、契约、工具）→ 一次性工人，并发有益，反射层自动补员。
* **监督**（审计/合并/浏览器/回顾）→ 四个运维，不产研究成果，只保证前三类不出错。

两条新机制：
1. **常驻研究员可在自己赛道内自行下发**（上限 3 件未完成），供货不再卡在监控一个人；
2. **工作板按阶段焦点排序**：当前焦点 campaign > paper，同优先级下焦点赛道先被领走。

完整的权限表在 `monitor/CHARTER.md`，每周期读一遍。
