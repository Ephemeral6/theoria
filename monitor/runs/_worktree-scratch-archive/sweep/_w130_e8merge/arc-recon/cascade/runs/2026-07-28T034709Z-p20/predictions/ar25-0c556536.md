## The discriminating observation

The verdict for *this* game turns on `n_frames` alone at the first level, and on
`intra_batch_changes` at the second. I would call this game
`action -> frame SEQUENCE` if any step returns `n_frames > 1` **with**
`intra_batch_changes >= 1` — that is, one command producing several genuinely
different world states, so that a single-frame model silently discards
intermediate states a rule miner would need. I would call it
`action -> single frame, the list being just a container` if every step returns
`n_frames = 1`, which is what the precheck saw nine times out of nine and what I
am predicting. The awkward middle case — `n_frames > 1` with
`distinct_frames = 1` — is padding, not a cascade, and would still leave
D-A0-004 defensible for this game, though it would prove the list is not merely
a degenerate container either.

What would surprise me, in descending order of surprise: (1) any batch with
`n_frames > 1` at all, since two prior sessions produced exactly 1 frame nine
times each and the spec nominated this game precisely because it looked inert on
that axis — a cascade appearing here would mean the batch size is a function of
*state*, not of game or action, and would make the precheck's nine single frames
a fact about the states those nine steps happened to visit rather than about
`ar25`; (2) a batch-hash mismatch at any step, since that would mean either
cross-session residue (a third session's RESET does not restore the same opening
state) or non-determinism that two runs 2 minutes apart could not see, and it
would put the entire offline-expectation method of this probe in question, not
just this game; (3) `first_equals_prev_last = True` anywhere, which would mean
an action I predicted to move the world was in fact a no-op and the precheck's
distinct hashes came from something other than the grid. I am predicting a
completely boring, fully-matching, all-`n_frames=1` run, and I expect to be
right; the value of writing this down is that if the run is not boring, the
prediction was on disk first.
