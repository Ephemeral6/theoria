# O3 — 22 acceptance entry points, audited blind

判据 for 有负控 (mine, since none was given): **是** = an executable artefact drives a
deliberately bad/broken input at *this* file and asserts the refusal or red verdict that
comes back. **部分** = an executable control exists but sits one step away — it exercises a
component this file leans on, or asserts a report field going red rather than the file's own
refusal, or asserts the refusal by grepping the source text instead of running it. **否** =
nothing executable; prose, or the inverse control (a test that it must *not* fail).

Paths are relative to the tree root. Line numbers are of the file named in the column unless
another file is named.
