## 3 · 刀口落在 U2 与 U3 之间

`Theoria.md:262` 是框架**自己预先注册**的理解序数尺:

> 说明书对上过去了吗(U1)/ 说得清吗——是可检查的文本而非散文(U2)/ 证得动吗(U3)/
> 被打脸后修得好吗(U4)。裸 agent 没有说明书,U1 都不满;Schema 止步 U1;Theoria 目标 U3/U4。

- **U1–U2 = 表示层**:对象化、DSL、可检查文本、重放。委任状说的"只留表示层"就是这两级。
- **U3–U4 = 证明层**:证得动、被打脸后修得好。

**⇒ 刀口 = U2|U3 边界。** 三条互相独立的论证都落到同一处:

1. **委任状**说"只留表示层",而表示层在 U 尺上就是 U1–U2;
2. **certify 的两层**(廉价/昂贵)恰按同一条线分:廉价层检的是 U1,昂贵层检的是 U3;
3. **§1.3 的构造性漏洞**(`Theoria.md:32-36`):重放抓得到写错的规则,构造上抓不到漏写的规则,
   §1.4 因此要求第二种检验。U1–U2 全属第一种,U3–U4 全属第二种。

于是本臂的定位一句话讲清:**它是 U2 臂。** 比 Schema(止步 U1)高一级,比 Theoria(U3/U4)低一级。
它正是一个只读了论文表示层那一半的评审员,自己能搭出来的最强的东西——
"你只是发了 diff"这一拳,打的就是这个臂;本臂存在的意义,是把这一拳**接下来、量给他看**。

## 4 · 精确刀口:切在调用点上,不是切在 DSL 上

母体勘查交回一条与直觉相反的事实,它决定了刀口的实现位置:

> **`gen_lean_a0.generate_lean` 从不引用 `ast.laws`。** 全仓 grep,A0 只命中
> `unsolvable_variant.py:197`、`concept_account.py`、`tests/`。DSL 里的 `invariant` / `theorem`
> 子句**只渲染成 markdown 散文**——它们是"义务的声明",不是义务本身。

⇒ **删 DSL 的 `laws:` 段一条 Lean 定理也砍不掉。** 真正的义务由三个调用点创造:

```python
lean = generate_lean(ast, prob, theory_py,
                     invariant_builder=builder,   # weight_invariant(region, arena, comment)
                     goal_cell=goal_cell,
                     unsolvable=unsolvable,       # ← 这个 kwarg 发出 theorem unsolvable
                     semantics=semantics)
```

**刀口的执行形式,五条,逐条可查:**

| # | 切什么 | 位置 |
|---|---|---|
| C-1 | 不调 `generate_lean` —— 根本不生成 Lean 形态 | 编译驱动 |
| C-2 | 不调 `lean_check` / `certify_a2.lean` —— 不存在昂贵层 | certify 驱动 |
| C-3 | `region=None, goal_cell=None, unsolvable=False` —— 不构造不变量,不索取证书 | 编译驱动 |
| C-4 | plan 的 UNSAT **直接定案**,不触发证书义务、不触发定向戳探 | plan 驱动 |
| C-5 | 玩法书定理级条目(`[proof: lean]` / `[admissible: lean]`)降为经验级,只携节点账 | 玩法书 |

**DSL 侧的处置**:`laws:` 段**保留 invariant、删 theorem**,并且 invariant 的
`[status: proven]` 一律改写成 `[status: empirical]`。理由:委任状说的是"降级",不是"消失"——
经验层仍然可以观察到"红蓝奇偶恒定",它只是**没有证明**。让 `theory.md` 把这句话照实印出来,
本身就是消融臂最诚实的展品:一本读起来几乎一样、但每一条全称断言都没有担保的说明书。

**取第 1 档,不取半刀。** 母体还有两个更弱的开关(`unsolvable=False` 但保留 `inv_*`;
或 `invariant_builder` 返回 `true` 让证明变空)。两者都会留下"有证明但不证不可解"的中间态,
归因不干净。全切。

## 5 · 一字不改的部分(归因的另一半)

差异可归因,靠的不是"我切得准",而是"我**没动**的那些确实一字未改"。以下逐项**导入母体的库函数**,
不复制、不改写:

| 保留 | 来源 |
|---|---|
| 世界与探索器(轨迹生成) | `world.explorer` / `a2world.*`,无 RNG,字节可复现 |
| 六台引擎全套调用 | `pipeline.engines_stage.run_stage`(MDL 分割、CEGIS 挖掘、zero_space、probe_frontier) |
| 对象化 / 分割算子选择 | 同上 |
| DSL 解析 | `theory-compiler` 的冻结 v0.1 语法 |
| Python / PDDL / Markdown 三个生成器 | `gen_python_a0` / `gen_pddl_a0` / `gen_markdown` |
| 廉价层 certify 四查 | `certify.replay.certify` —— 转移重放、渲染逐格、全帧责任制、终点一致 |
| 规划器 | `fd_adapter`,同一后端同一档位(`stub-bfs`) |
| 候选箱格式 | `CONTRACTS/candidates_schema.md` 冻结 v0.1,append-only |
| 外环 observe→execute→record | `Theoria.md:220` 要求"故意一字不改" |

**引擎照跑,包括 `zero_space` 与 `lp_potential`。** 这一点容易切错:它们产出的是不变量与
pagoda 权重,看起来"属于证明层"。但 `Theoria.md:214` 分工三律第 3 条说引擎调用不计模型调用、
输出确定可复演;`Theoria.md:376` 切的是**定理义务**,不是**引擎**。所以本臂照常调用它们、
照常把提案灌进候选箱——**变的只是裁决:同一条不变量,全量臂收作已证定律,本臂只能收作经验规律。**
这样引擎侧的成本在两臂之间完全相等,账单差异才干净地归到证明燃料上。

## 6 · 刀口的四道影子(推论,不是第二刀)

以下四项随主刀口一起消失。它们**不是**独立的切口——切掉它们的是同一把刀,因为它们的触发器
本身就是证明义务。逐条登记,是为了让"本臂与全量臂的差集"能被 `verify.sh` 精确断言:

1. **定向戳探**(约束 7 + `Theoria.md:230` 的"针对该定理依赖子句的定向戳探")。
   触发器是证书义务;义务没了,主语没了。**前沿驱动的戳探不受影响**(见 §7)。
2. **依赖驱动的重证**(`Theoria.md:111`:"说明书改一条规则,依赖它的玩法条目自动作废重审")。
   降级后条目本来就没有证明可作废,重审无事可做。A2 的 `repair.reprove_stale` 整拍消失。
3. **`ArenaEscape`**(`gen_lean_a0` 在生成期发现"手册的 step 逃出它自己声明的状态空间")。
   这一检查只在 Lean 生成期发火,廉价层看不见。不生成 Lean ⇒ 这道检查一并没了。
   **这是一道本臂自己都没意识到会失去的检查**,正是消融要量出来的东西。
4. **"证明失败"这一种意外**(`Theoria.md:233` 经验族五种之一)。七种意外降为六种。
   本臂里"证明失败"**构造上不可能发生**。

外加一项**不属于影子、属于降级**的:约束 9 的无歧义。廉价层的 `AmbiguousTransition` 是
**运行期**捕获(碰巧撞上才报),而"恰一后继"的**证明**在昂贵层。消融后,无歧义从"定理"
降为"这次没撞上"——这正是 `Theoria.md:247` 那句"桌游的'以第 X 条为准'升级为证明义务"的逆操作。

## 7 · 最难的一处:是什么让回路转起来

### 7.1 一个不能糊过去的事实

母体勘查(`02-a2-anatomy.md` §1)发现:**A2 实现里的打脸不是定理驱动的。**

```python
"refuted": bool(episode["final_win"]),      # a2pipeline/refute.py
```

`episode` 来自裁判自己的世界解算器 `A2World.solve()`。`refute.py` 确实读了
`exhibit_report.json`,但只取四个键拼一个**纯展示用**的 `claim` 块,那句
`"says": "no reachable state satisfies Goal…"` 是**硬编码散文**。
**没有一行代码比较过反例与定理。** 而且没有任何东西*触发*这个回路——
`refute`/`locate`/`probe`/`repair` 是 `run_all.py` 的 `STEPS` 里无条件列出的第 7–11 步。

工单写的"没有证明义务就没有打脸机制",在**框架层面**(§1.4 + 约束 6)成立,在 **A2 的实现层面
不成立**。照实登记。

### 7.2 于是不能这样做

**不能**把 `refute/locate/probe/repair` 从步骤表里删掉,然后报告"消融臂修不好"。
那是**手工拆掉回路再宣布回路不转**,评审一拳打穿,而且它会把 §1 的约束 (B) 违掉——
差异就不是刀口造成的,是我造成的。

### 7.3 正确的做法:两臂共用一条由「意外」驱动的回路开关

`Theoria.md:233` 给了框架自己的答案:

> 回路由**意外**驱动,意外七种、分两族……**有意外才回 theorize**;无意外时 plan/commit 静默运转,免费。

⇒ 本臂实现一条 **意外总线**(`ablcore/surprise.py`),两臂共用同一条,同一套判据:
每一拍把自己产生的意外投进总线,驱动器**当且仅当**总线非空时回 theorize。
于是回路转不转不再是驱动脚本作者的决定,而是**从刀口推出来的**:

| | 全量臂 | 消融臂 |
|---|---|---|
| plan 得到 UNSAT | 约束 6:**欠一张证书** → 生成不变量 → Lean → 定理的 `depends` 子句 → 约束 7:**定向戳探那些子句** → 戳探打脸 → **意外** → theorize | 约束 6 已切:UNSAT **直接定案**。无义务、无定理、无 `depends`、无定向戳探 → **总线空** → 回路不转 |
| 廉价层 | 绿(184/184) | 绿(184/184) —— 一字未改,必须相等 |
| 结论 | "不可解"这个判决**未定案**,还欠戳探 | "不可解"**已定案**,归档,继续 |

野外(Phase 3/4)全量臂发现假不可达的真实路径就是右上角那一条:证书义务 → 定向戳探 → 打脸。
A2 的 `refute.py` 是这条路的**离线替身**——它用裁判的解算器直接给出反例,因为离线世界有裁判而
野外没有。**替身的存在不改变:替身替的是谁。** 消融臂两个触发器(约束 6、7)都被切掉,
所以它连替身该在哪里出场都不知道。

**回路不转是刀口的推论,不是我删掉的步骤。** 这是本设计最重要的一句话。

### 7.4 戳探留不留 —— 一处必须自己裁决的模糊

基准两处口径不完全重合:

- `Theoria.md:376`:必设臂叫"− 定理义务",可选臂叫"− 戳探" —— 读作两把**各切一刀**的臂;
- `Theoria.md:417`(§3.2 消融节):"{仅重放} vs {+定理} vs {+戳探}" —— 读作**嵌套三级**,
  则第一级"仅重放"既无定理也无戳探。

**裁决:戳探这一拍留下,一字不改;其中由证明义务触发的那部分随主刀口消失(§6 影子 1)。**

理由是 §1 的约束 (B):一次切两刀,A2 上的失败无法归因于哪一刀。单刀口是唯一可归因的做法。

**代价照实登记:本臂并不等同于 §3.2 的"仅重放"那一格,而落在"仅重放"与"+定理"之间。**
`verify.sh` 会把"因刀口而消失的定向戳探"逐条数出来——那是这道影子的尺寸,也是本臂与
"真·仅重放"之间的距离。若日后要补 §3.2 的第一格,那是另一个臂(− 定理义务 − 戳探),不是本臂。

## 9 · 三件标定展品

`Theoria.md:259` 的判决题分三类,灵敏度与特异度一起打分。本臂的标定按这三类组织:

### E1 · A0 变体 —— 真不可解(判决题第 (i) 类)

A0 的 `no_button` 变体是**真**不可解(`unsolvable_report.json` 的 `constructive_ground`:
没有 Button,`door_opens_left` 的守卫永不成立,目标房间构造上不可达)。

⇒ **消融臂给出与全量臂逐字相同的判决,而且是对的。** 这不是本臂的失败,是它最重要的那一半证词。
对上基准原文:

> 小空间不可解——穷举可行,连 Schema 的完备搜索都会正确地停,**甚至可能因漏边而以错误的理由
> 得到正确的判决**,所以这里考的是理由:证书,还是"我搜过了没有"。

**E1 的证词:判决相同,理由蒸发。** 它证明在判决层面上度量根本分不开这两个臂,必须去看证书。
全量臂在同一处留下 `axiom_reports [{"axioms": [], "name": "unsolvable"}]`;本臂那一栏是空的。

### E2 · A2 展品 —— 漏写规则造成的假不可解(工单指定)

带洞手册(缺 teleport)在游戏记录上重放 184/184 全绿,plan 返回 UNSAT,而世界 18 步解出。

⇒ **消融臂照信不误**:UNSAT 直接定案,总线空,回路不转,归档"本关不可解"。
全量臂在同一处欠一张证书,并因此走完打脸→定位→戳探→修订→重证→解出。

**E2 的证词:判决不同。** 本臂在一个**可解**的关上宣布不可解——`Theoria.md:259` 第 (iii) 类
特异度失败的最坏形态("敢说'不可解'的框架必须在这里闭嘴")。

### E3 · 善意变体 —— 把反例白送给它,它还是不行(对抗审查线)

**这一件不是工单要求,是为了防守评审必然会打的那一拳:"你没给它反例,当然它修不好。"**

母体勘查交回一条**反驳我先验论证**的事实:`locate.py` 在消融后**逐字节存活**——它只需
`theory.py` 与一条真实解路,做三查(棋盘看错 / 某步预测错 / 终点判断错),不读任何 `.lean`。
⇒ **善意的消融臂,被白送一条解路时,是能定位的。** 照实修正,不掩盖。

那么证明到底买到了什么?**买到的不是"能定位",是"三选一穷尽"。** `Theoria.md:43` 的反证——
"若三处全对,这条路在模型里也走得通,与**证明了**不可能矛盾"——依赖"证明了"。
规划器的 UNSAT 不是证明:它可能只是编码/接地坏了。本仓库有这个第四支的实证——
**D-A2-006**:PDDL 后端接不出 teleport 的 `?p - markedcell`,于是对一份**有** teleport 规则、
step 完全正确的手册返回 UNSAT。

**E3 因此可构造**:拿**完整**手册(有 teleport,step 无缺陷),关掉 D-A2-006 的绕开
(`pddl_addressable`),编译 → 规划器返回 UNSAT → 消融臂定案"不可解"。
再把世界的解路白送给它:

- 三查**全绿**(棋盘对、每一步都对、终点判断对),`culprits == []`;
- 反例仍然摆在那里。

**三选一回来一个空集。定位退化成"不知道"。** 而全量臂在同一份手册上根本走不到这一步:
索取证书时 Lean 会拒绝(目标本来就可达,不存在把它隔开的不变量),假断言从来没机会被说出口。

**E3 的证词:证明义务的作用不在事后修,在事前不让假断言出生;以及,它是三选一穷尽性的唯一担保。**
