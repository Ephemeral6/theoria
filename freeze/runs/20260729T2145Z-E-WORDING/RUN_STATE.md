## 二、订正了别人也订正了自己

* **订正审计的算术**：原稿说「⟨m⟩ ≤ 13 时 clean 层在结构上不可能显著」。
  按 Holm 降幂阶梯逐级重算：**⟨m⟩ ≤ 12（clean ≤ 5）任何一级都不可能**；
  **⟨m⟩ = 13（clean 6）只在最松那级（α = 0.05）可能**，即只有另两个终点都已显著时；
