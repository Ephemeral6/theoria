## 一、三个空洞的处置

### 空洞 1 —— 没有 ⟨X_clean⟩：铸了，并把「两层一致」换成一个合取

⟨X⟩ 一个符号同时要满足 claim 层 14/19 = 0.7368 与 clean 层 10/12 = 0.8333。
一个符号扛不住两个数，于是成立版给 clean 层**没有过线**，只有「两层一致」——
一个**未定义谓词**，再叠上「分歧时以弱者为准」，整个 clean 层裁决就是看到数字之后的判断。

**做法**：在 `STATS_RULES.md` §1.2 铸一张四符号表，两份文件同批：

| 符号 | 是什么 | 谁定 | 取值范围 |
|---|---|---|---|
| ⟨X⟩ | claim 层**过线** | 人，开跑前落盘 | [10, 19]，建议 14 |
| ⟨X_obs⟩ | claim 层**实测** | 数据 | [0, 19] |
| ⟨X_clean⟩ | clean 层**过线** | 人，**与 ⟨X⟩ 同批** | [7, 12]，建议 10 |
| ⟨X_clean,obs⟩ | clean 层**实测** | 数据 | [0, 12] |

注意 ⟨X_clean⟩ 的角色**与此前用法相反**：`CLAIMS_TEXT.md` 原先拿它当实测数用
（`⟨X_clean/12⟩`）。一套文件里同一个下标不能一处指过线、一处指实测，故统一，
实测改用 ⟨X_clean,obs⟩。

**真正买到的东西是这一行**：

> **C1 成立 ⟺ ⟨X_obs⟩ ≥ ⟨X⟩ 且 ⟨X_clean,obs⟩ ≥ ⟨X_clean⟩。**

「以弱者为准」在本终点上就是合取，没有第三种读法。写成合取之后，
「两层一致」这个谓词不再需要存在，也不再需要有人在看到 0.737 与 0.833 之后
去判断它们算不算一致。

### 空洞 3 —— 闸门反向锁死硬下限：解开的方式是给它一份工作，不是删它

上一世登记的是「先定硬下限留不留」，并把它挂成待监控裁决。**不需要监控裁决，
因为两个选项都错**：

* **删**：⟨X⟩ 与 ⟨X_clean⟩ 都是人选的整数，硬下限是那个**选择区间的下端点**。
  删掉它，「人选定一个 ⟨X⟩」就没有下界，⟨X⟩ = 1 满足所有条款。
* **照原样留**：IDENT 硬性要求 `硬下限10` / `硬下限7` 出现，
  等于强制维持一个刚被判定不许当过线的数字的显著性。

**做法**：给它一份定义清楚的工作，然后要求那份工作的说明书**与数字同行**。
§1.3 补第二条裁定，两句必须一起出现：

> **开跑前是下界，开跑后是零。**

只说前半句，硬下限变回备用过线；只说后半句，就会有人把它删掉。
闸门侧新增 bespoke 检查 `E1/hardrole`：**只要文件里出现 `硬下限`，
同一文件就必须同时出现 `取值下界` 与 `开跑前是下界，开跑后是零`**。
IDENT 的两条因此可以正当地继续硬性要求那两个数——它们现在有工作了。

顺带补上 cycle 38 记的第 3 条：clean 层硬下限此前**在 §1 里根本没出现过**，
只活在 §5 的定标表与 §9 的待决表里。现在两个下界都写在 §1.3。

### 空洞 2 —— C1 的不可结论版：不是新规则，是一条被反着写了的旧裁定

这一条比工单写的更重，因为查下去发现**它早就被裁定过**。
`RECONCILE.md` 的 **H-4**（逐字）：

> 另设第二道闸（G7 的 U3 版）：若重跑后仍无有效 episode 的**局数**
> 达该层的 1/3……U3 判**不可结论**，既不支持也不否证 C1。

同文件「问的问题本身错了」第 3 条把理由说得更明白：「G7 原文的 1/3 上限是
**按对数**算的，只覆盖配对终点。所以 U3 需要一条**按缺格局数**重述的版本——
**否则 U3 根本没有第二道闸**。（**已按此裁定**。）」

而 §4.1.0 与机械规程此后都写着 C1 没有第三版、并说「这是有理由的而不是漏了」。
**那是漏了**：一条已裁定的规则被后来的编辑反着写了一遍。

**「没有剔除所以不会不可结论」是个非推论。** 固定分母关掉的是**分子分母被搬动**；
它对**哪些格根本没能被测量**什么也没做——而后者正是 §4.1.0 自己写下的立条理由
（「那 5 对是被基础设施而非被随机性选出来的」）。固定分母只是把一个方向未知的偏倚
换成一个方向朝下、**大小未测**的偏倚。而且本文件**已经在另一个终点上承认过这条逻辑**：
§2.3.2 给终点二设了一个与剔除无关的不可结论出口（`coverage_positive` < ⟨c_min⟩，
「**不是判为不成立**」）。

#### 触发量：枢轴性，不是比率（§1.4.2）

设每层：**a** = 达成局数，**d** = 臂始终未取得一次有效尝试的局数，
**g** = 该层缺格局数（跑出了 episode 但检查不了；与 d 不相交）。

| 序 | 条件 | 该层裁决 |
|---|---|---|
| 0 | `d ≥ 上限`（claim ≥7、clean ≥5） | **不可结论**——有效尝试的局数本身不够，**无论 a 多大** |
| 1 | `a ≥ 过线` | 成立 |
| 2 | `a + d + g < 过线` | 不成立（**即使把每个状态未知的格都算作达成**也够不着） |
| 3 | 其余（`a < 过线 ≤ a + d + g`） | **不可结论**（裁决悬在从未被测量、或测了查不了的格上） |

**分母一格不动**，d 与 g 都不从任何地方减去；§1.2.1 的「缺格是一个标签，
不是一次减免」原封不动。

**第 0 行与第 2 行的 g 都是本轮对抗性复核加的，两条都补的是真窟窿**——
下面第 2、4 条同样是复核推翻我的第一版之后的订正，逐字留在这里而不是抹掉，
因为**这份报告如果只印第一版的四条理由，它自己就成了 §7 要禁的那种事后改口**：

* **没有第 0 行时第 1 行会漏判。** 我第一版给第 1 行写了「d 无关」，
  而 §1.3 允许人把 ⟨X⟩ 选在 [10, 19]：**⟨X⟩ = 10、a = 10、d = 7** 完全合法，
  第 1 行判**成立**，而 19 局里有 7 局一次有效尝试都没有过。
  「地板仍然过了」这个理由只在 ⟨X⟩ = 14 时成立（那时 `a ≥ 14` 算术上蕴含 `d ≤ 5`），
  而我从没写下它依赖的那个区间限制。第 0 行把 H-4 的天花板原样接回来。
* **第 2 行不含 g 时会原样重造本轮要修的那个缺陷**：13 局达成、6 局缺格、d = 0 时
  `13 + 0 < 14` 判**不成立**，于是论文逐字印出主结论——而那 6 局从来没被评估过。
  g 可以进第 2 行却仍不进 d，是因为方向不同：进第 2 行只用来**阻止**「确定失败」
  这个断言（保守方向，且第 1 行只看 a，买不到成立），进 d 则会喂给第 0 行那个
  更舒服的出口（激励方向）。

四条理由，其中两条已按复核订正：

1. 不是剔除率，§1.2.1 关掉的通道仍关着；
2. **第 1–3 行不引入新旋钮，但整条规则不是无旋钮的——我第一版说过头了。**
   第 1–3 行的阈值由 ⟨X⟩ / ⟨X_clean⟩ 推出、自动跟着地板走，**但 d 本身依赖 ⟨R⟩**
   （§7 的重跑上限，§9.7 记为 `needs_human`、**至今未定死**，且**不在 `FLOORS_DIGEST`
   的封印范围内**）。按 `P(该格进 d) = q^{n(1+R)}`：q = 0.5719 时 R = 3 给 0.011、

   即从「这个出口几乎不触发」推到「它总是触发」。故 **⟨R⟩ 必须开跑前定死并纳入封印**
   （§9.7 新增一行）。同源第二通道：重跑要花钱，而 §5.7.2 已有先例——ar25 那三格

   clean 层 ⟨X_clean⟩ = 10、**d = 3** 时上限 9/12 < 10，而 3 < 5。

#### d 只收一种「没能尝试」（§1.4.3）

* **收**：§7 的未决格——达到重跑上限仍无有效 episode，成因取自 harness 写的 outcome。
* **不收 §7 作废判据的第二支**（< 8 turn 终止）：臂可以自己停手（是杠杆），
  且 §5.7.5 已写明「**U3 根本不要求 episode 走完**」——那一支是给 E2 的形状指标用的。
* **绝不收有效结局**（`budget_exhausted` / `game_over` / 赢）。这是最要紧的边界：
  §5.7 记着 D-016 之后 `api_unusable` 需 10 次连续失败而包络最长连败是 5，
  于是「在今天的 harness 下这 48 集会记 **0 个 `api_unusable`**，结局是 `budget_exhausted`」。
  **把有效结局收进 d，C1 就永久自动不可结论**——主骨在本仓最常见的结局上变得不可证伪。
  这不是假想的钻法，是默认行为。
* **缺格局不进 d，但进第 2 行的 g**（§1.4.4）：不进 d，是因为它的判据含结果量
  （要跑臂产出的定理），§7 明令判据不得出现结果量；且 §1.2.1 那条切分是在缺格
  **没有后果**时做的，一旦它喂给一个比不成立舒服的出口就变成承重的。要让它进 d，
  须先重定义成局级、先验、与臂产出无关的状态空间上界 + 冻结算力预算。
  进第 2 行则相反：那只用来阻止「确定失败」这个断言，是保守方向。
  在此之前强制披露缺格局数与逐局理由。
* **d 的值域本身不是臂无关的，照录**：见上一节第 4 条——`api_unusable` 数的是
  臂自己发出的动作连续十次非 200，于是「臂可以自己停手」这条排除 8-turn 支的理由

#### 两层合成与「不可结论不得比不成立便宜」（§1.4.5）

1. **任一层 `a + d + g < 过线` ⇒ C1 不成立**——成立要求合取，而这一层**无论没测到、
   或测了查不了的格是什么结果都过不了线**，合取因此确定不成立。（这比「有枢轴就
   不可结论」更决定性，且同样封闭：要躲开只能让 `a + d + g ≥ 过线`。）
2. 否则任一层不可结论 ⇒ C1 不可结论；
3. 否则两层皆成立 ⇒ C1 成立。

**不可结论必须比不成立更贵**：判为不可结论时逐字文本必须给出不成立版会给的
**一切**（a、两层比率与 CP 区间、逐局失败归因，**按「所有死格计为未达成」算**），
再加上一句不成立版不需要的承认（「有 d 局我们没能取得一次有效尝试」）
与实测 q / 暴露量 / 重算出数率。**选不可结论永远不比选不成立少写一个字。**
且实测功效**不得倒过来当触发器**——那是看着数据选裁决。

#### 顺带订正一个名字：0.3739 不是「功效」（§1.4.7）

`power_at(n,q,floor_k,cells) = _binom_sf(floor_k, cells, 1 − qⁿ)`，
而 `1 − qⁿ` 是 `cell_yield`（「一格至少一个 rep **出数**的概率」）。所以

> **0.3739 = P(19 格里至少 14 格出得了数)**，是**出数率**，不是检出功效。

又因为没出数的格留在分母里且计为未达成，「至少 14 格出数」是「至少 14 格达成」的
**必要条件**。于是 **0.3739 是「C1 成立」概率的上界，且是在臂完美的前提下的上界**——
**即使世界理论每一局都证得动，论文印出「C1 不成立」的概率 ≥ 0.626**。
`POWER` / `power_at` / §5.7.2 表头「功效」这几处命名把它说大了；
本轮不改代码符号（要动封印与闸门），但逐字记下区别并强制披露时按此措辞。

## 二、机械规程：第 7 条有个洞，而且不是本轮开的

第 7 条（本文件自称「最重要的一条」）只有**一个**触发词：不成立。
而 C4 早已有不可结论版（两条入口），C1 现在也有——**主骨判为不可结论时，
第 7 条整条不触发**：没有重写义务，而本文件又从未规定标题与摘要原本是什么，
于是标题保持原来的肯定口径、主骨其实没被测到，C2 顺势成为事实上的主张。
**那正是第 7 条要禁的「事后换主张」，只是从它唯一不看守的那扇门进来。**

**这个洞不是本轮开的，是本轮发现的**：它对 C4 已经敞了一段时间。已补：

* 第 7 条对「不成立」与「不可结论」一视同仁——标题与摘要**必须写明一个主骨终点
  未被测到**，且不得把 C2/C3/C5 提进标题或摘要；
