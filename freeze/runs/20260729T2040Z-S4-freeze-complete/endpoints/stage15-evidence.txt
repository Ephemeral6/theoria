2. NEGATIVE CONTROL FOR build_engine_manifest.py -- IT FIRES
==============================================================================
Stage [13]'s mechanism does NOT transfer verbatim, and the reason is a finding:

  freeze/n_feasibility.py contains no `HERE`, no `REPO`, no `__file__`, no
  os.path.join and no open() -- it is pure arithmetic.  That is why copying the
  single file to $(mktemp -d) and sed-ing a constant works there.

  build_engine_manifest.py pins  HERE = dirname(abspath(__file__)),
  REPO = dirname(HERE), OUT = HERE/ENGINE_MANIFEST.md, does
  sys.path.insert(0, HERE) to import build_manifest, and shells out to git with
  cwd=REPO.  A bare copy in $TMPDIR therefore has the wrong REPO, no
  build_manifest to import, and no repository to run git in: it would exit
  non-zero for reasons that have nothing to do with the artefact, and a control
  built that way would report "fires" while proving nothing.
  Same shape for build_budget_table.py (HERE/REPO/OUT_JSON/OUT_MD, plus
  REPO/proxy/... reads).  This is the V24 "battery blind hardcoded path" defect
  class: the verifier cannot be pointed at a copy of its own artefact.

  It is WORKED AROUND, not fatal.  Pin HERE to the real freeze/ (so REPO,
  sys.path, git and every companion read stay correct) and redirect ONLY the
  artefact path.  Two sed expressions.  The tmp path must be converted to a
  native path first, because a sed replacement string is not MSYS path-mangled
  and Python on Windows cannot open /c/Users/....

Setup actually run:

  here_py="$(cd "$HERE" && python -c 'import os;print(os.getcwd().replace(os.sep,"/"))')"
    -> C:/Users/user/Desktop/theoria/.worktrees/s4-freeze/freeze
  tmp="$(mktemp -d)"           -> /tmp/tmp.pKlCeHjSvH
  tmp_py                       -> C:/Users/user/AppData/Local/Temp/tmp.pKlCeHjSvH
                                  (outside the repo tree -- checked)
  cp freeze/ENGINE_MANIFEST.md "$tmp/"
  sed -e 's|^HERE = os.path.dirname(os.path.abspath(__file__))$|HERE = r"<here_py>"|' \
      -e 's|^OUT = os.path.join(HERE, "ENGINE_MANIFEST.md")$|OUT = r"<tmp_py>/ENGINE_MANIFEST.md"|' \
      freeze/build_engine_manifest.py > "$tmp/bem.py"

  resulting lines 73-75 of the copy:
    HERE = r"C:/Users/user/Desktop/theoria/.worktrees/s4-freeze/freeze"
    REPO = os.path.dirname(HERE)
