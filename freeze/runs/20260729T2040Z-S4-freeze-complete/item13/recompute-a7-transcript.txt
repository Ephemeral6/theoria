Neither basis measures ANY of the three primary endpoints. On the one

Theoria.md:368: 'variance small => n=1 defensible, otherwise n=2'.
A 20x disagreement between two tracked measurements of the
same quantity is not 'variance small'. It is 'variance unknown'.
'Otherwise' covers unknown. => n = 2, with and without ar25.

BUT NOTE WHAT DID FLIP, in section 3 above: on the A7 basis the SURROGATE
dispersion test flips on ar25's inclusion --
  excl ar25: max within-game CV 0.0370 < 0.10  => 'small' => n=1 defensible
  incl ar25: max within-game CV 0.2756 >= 0.10 => 'not small' => n=2
So any n argument resting on the CV number is FRAGILE: one game's standing
decides it. The argument that does NOT flip is the endpoint argument --
0 of 3 primary endpoints measured, levels_completed identically 0, in every
subset of every basis. n=2 survives on that, and only on that.
