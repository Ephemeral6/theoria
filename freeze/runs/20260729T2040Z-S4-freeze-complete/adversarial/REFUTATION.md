### B.1 U3 不需要一个跑完的 episode，但 §7 照样把它作废掉

§1.2 的 U3 单局判据逐字（`STATS_RULES.md:77-82`）只要求**产出物**：

> 该局的 Theoria 臂产出**至少一条机器可查的定理**，且该定理 (a) …Lean 形态编译通过，
> (b) `#print axioms` 只报告白名单内的公理，(c) 其陈述**非平凡**

**没有一个字要求 episode 跑到某个结局。** 一条在 API 挂掉之前生成并编译过的定理，
按 (a)(b)(c) 就是达成。

但 §7 的作废判据（`:861-863`）是**按 outcome 判、跨终点一刀切**的：

> 某个 episode 作废且重跑，当且仅当它的 `outcome` ∈
> {`api_unusable`, `model_error`, `harness_error`, `no_reset_window`}，
> **或**它在 `MIN_TURNS_FOR_SHAPE`(=8) 个 turn 之前终止

所以在**现行草稿之下**，§5.7 的乘法对 U3 也是自洽的：`api_unusable` 的 episode
连同它产出的定理一起作废。**这一点上 §5.7 不该被推翻。**

**但这暴露了一个 §5.7 从未考虑的、零成本的替代修法。** §5.7 的结论是

## E. 「正相关让 n 买得更少」的方向 —— **SURVIVES for n=2，对 n ≥ 3 as-written 为假**

### E.1 n=2：精确成立，无懈可击

固定边际 q，令 Xᵢ ∈ {0,1} 为 rep i 死亡的指示量，ρ = Corr(X₁,X₂)：

    P(两个都死) = q² + Cov(X₁,X₂) = q² + ρ·q(1−q)  ≥  q²  ⟺  ρ ≥ 0

**⟨n⟩ 的裁定值就是 2，所以对这一条裁定，§5.7 的论断是恒等式级别的正确。**

### E.2 但「正相关」推不出 n ≥ 3 的界 —— 构造出的反例

逐字的说法是（`:809-811`、`n_feasibility.py:31-33`）：
「正相关只会让 qⁿ 更大 … **上表是 n 的上界表现**」。上表有 n = 3, 5, 10, 20, 64，
而**结论的落点（n ≈ 63 / 64 → 14.06）全在 n ≥ 3 那一侧**。

对 n ≥ 3，**逐对正相关不含蕴 P(全死) ≥ qⁿ**。可交换三元反例（数值已复核）：

    P(000)=0.18,  P(恰一死)=0.08 各,  P(恰二死)=0.16 各,  P(三死)=0.10
    → 概率和 = 1，边际 q = 0.50
    → P(某两个都死) = 0.26 > q² = 0.25，故 ρ = +0.04 > 0（逐对正相关）
    → P(三个都死) = 0.10 < q³ = 0.125

**逐对正相关，而三死概率低于独立情形。** 所以按 §5.7 写的假设
（「`api_unusable` 在同格 rep 之间正相关」），n=64 那一行**不是**上界。

**修法是一个词，不是一段。** 物理上对的模型是**共同冲击**：Xᵢ = 1 若发生共同
故障（概率 π），否则独立以 r 死；q = π + (1−π)r。此时
P(全死) = π + (1−π)rⁿ = E[Qⁿ] ≥ (E[Q])ⁿ = qⁿ（Jensen），**对一切 n 成立**。
共同冲击模型是**关联**（associated）的，逐对正相关不是。把
「正相关」改成「共同冲击 / 关联」，这一条对所有 n 都真。

（顺带把提示里那条陷阱记下来：**如果不固定边际**，条件在一次共同故障上会同时抬高
边际 q，于是「正相关 vs 独立」的比较无从谈起——所以这一条论断唯一站得住的读法
就是固定边际的那一个，而 §5.7 没写「固定边际」。写上。）

### 判决：**SURVIVES**（对 n=2 精确）；n ≥ 3 的「上界」措辞 **NEEDS-REWRITE**

## H. 目标二：`MANIFEST_DRAFT.md` 13-b 的裁定 —— **NEEDS-REWRITE**

裁定逐字（`:434-439`）：⟨n⟩ 仍 = 2，三条理由。逐条打。

### H.1 理由 (1)「菜单是冻结条款」——不是一条理由，是一条**无权限声明**

`monitor/CHARTER.md` 的硬边界表：

**只有监控可以改契约。** 所以「n=3 需要改 `Theoria.md:368` 而不是选一份依据」

提一条 inbox 提案给监控。**这是 G 节那个模式的第二次出现**：

* 记一条：**`Theoria.md:368` 的 n=1/n=2 菜单是一个二值菜单，

### H.2 理由 (2)「两份依据都测不到三个主终点」——成立，但它证的比裁定多

这条我复核成立（`VARIANCE_BASIS.md:199` 两份、每个子集都是 0/3 主终点）。
**但它是一把双刃**：如果两份依据都测不到任何主终点，那么

而 §5.5 理由四把这件事读成「『否则』涵盖未知 ⇒ n=2」。那是一个合法的读法，
但它意味着 ⟨n⟩ 的值**不是被测出来的，是被缺省出来的**——
论文里必须这么写，而不是写成「开发堆方差定了 n=2」。13-b 没记这一句。

### H.3 理由 (3)「按 §5.7 的算术，2 与 3 都够不到任何地板，是在不起作用的旋钮上争」——**在 A 节之后倒掉**

### H.4 附带查实：13-b 标 ✅，但它自己的行文承认残余
