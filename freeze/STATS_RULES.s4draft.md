## 1. 单元、配对与聚合

### 1.1 一格是什么

一格 = （臂, 局）。每格跑 ⟨n⟩ 局（`n` 的定法见 §6，值见 PENDING_FIVE）。

### 1.2 为什么配对

同一局对不同臂是同一个世界、同一份出题、同一个打分器，天然配对；跨局的难度差异是
本实验里最大的方差来源，配对把它整块消掉。所以**一切主终点检验都是跨局的配对检验**，
不做跨局合并的独立样本比较。

### 1.3 n>1 时先聚合，再配对

**先把一格的 n 次塌成一个数，再做配对检验。** 不这么做就是伪重复（pseudo-replication）：
把同一格的两次当成两个独立样本，会把样本量凭空翻倍。

聚合函数**按终点类型预先钉死**：

| 终点类型 | 聚合 | 平局怎么办 |
|---|---|---|
| 二值（U3 达成） | 多数 | **n=2 且一胜一负 → 判为未达成** |
| 连续（判决题平衡准确率、前载指数） | 中位数 | n=2 时中位数即均值 |

**平局向不利于本框架的方向倒**，是有意的：这是我们自己的 claim，平局的解释权不该在
我们手里。写在这里，冻结之后就不再是选择。

### 1.4 缺格与未决

* 某局某臂**未产生可评的结果**（崩溃、超预算、`可解性裁决协议` 判未决）→ 该**对**从
  该终点的检验中剔除，剔除数与原因逐条入 incident ledger 并在论文里报。
* **剔除上限**：某终点被剔除的对数 > 全部对数的 **1/3** 时，该终点**判为不可结论**
  （inconclusive），不出 p 值、不进主张。理由：否则「让不利的局跑挂」就成了一条无声的
  调参通道。

## 2. 三个主终点，逐条给出可执行定义

Theoria.md 把主终点限死为三个。三个的**定义**在这里落成机器可算的形式；定义之外的
任何量都是探索性的。

### 2.1 主终点 A · U3 达成率

**U3 = 「证得动吗」**（Theoria.md 1.11 四个排序问题之三）。

**逐局二值判定，由冻结的打分脚本重算，不采信任何臂的自述。** 某臂在某局判为
**U3 达成**，当且仅当以下五条全部成立：

1. **有说明书**：该臂对该局产出了 `theory.dsl`（或该臂的等价手写物）。
2. **说明书对得上过去**：`certify` 廉价层全绿——全史重放 100%、渲染一致性全帧通过。
   （这一条即 U1；U3 蕴含 U1，阶梯是嵌套的。）
3. **有一条全称断言，并且证得动**：该局的 `theory.lean` 里至少有一条声明为
   `invariant` 或 `theorem` 的全称断言，`lean` 退出码 0，`#print axioms` 对它报告
   **空公理集**，或仅报告冻结时白名单内的公理（白名单：`propext`、`Quot.sound`、
   `Classical.choice`；**永不允许** `sorryAx` 与 `Lean.ofReduceBool`）。
4. **该断言不是空转**（见 §2.1.1）。
5. **该断言用的是这一局的词汇**：断言的自由符号全部出自该局 `theory.dsl` 的词汇表，
   且该 `theory.dsl` 就是第 2 条里通过重放的那一份（按哈希比对，不按文件名）。

**U3 达成率** = 达成的局数 / 该臂进入统计的局数。

#### 2.1.1 非空转条款——这是本文件里最容易被钻的一条，所以写得最长

本仓库已经**吃过一次**这个亏：一份 `I := true` 的 Lean 发展，三条义务全过、
`#print axioms` 为空、certify 整列绿，**什么也没证**（`cold-start-a3` 的 D-A3-007）。
「空公理集」这条通用判据分辨不出它。所以 U3 另加一条，**按断言的种类分别定义**：

| 断言种类 | 非空转要求 | 为什么这条堵得住 |
|---|---|---|
| 不可解性（`theorem unsolvable …`） | (a) 不变量在初始态成立；(b) **每个**目标态都被排除；(c) 初始态存在至少一个合法动作；(d) 该局的目标态集合非空 | `I := true` 死在 (b)；「目标集合是空的所以永远赢不了」死在 (d) |
| 守恒/不变量（`invariant …`） | 存在**两个可表示状态**使该不变量取不同值 | 恒真、恒假、以及「值域只有一个点」的伪不变量全死在这里 |
| 条件化不可解（死锁，`prune …`） | (a) 存在至少一个良构状态满足该模式；(b) 该模式不含目标态；(c) 该局**本身是可解的**，或存在另一条独立见证说明该模式不是「整局本来就输」的重述 | 条件无人满足的死锁定理死在 (a)；「整局已输」冒充死区死在 (c) |

**判定由脚本做，脚本随冻结包哈希。** 三种要求都是有限检查，检查量与状态空间同阶或更
小；跑不动的局按 §1.4 计为缺格，不按未达成计——「太大以致查不了」和「查了不算数」是
两件事。

**已知残余漏洞，照录**：一个臂可以写一条**真的、非空转的、但毫无难度的**不变量
（例如「棋盘尺寸恒定」）来换 U3。本规则**不**试图度量「有意思」，因为任何这样的度量
都会变成新的调参目标。代偿是两条：其一，U3 只是**排序问题**，Theoria.md 已明说四个
U 只排座次、不当证据；其二，主张的分量压在主终点 B 与 C 上，它们锚在**外部真值**
（出题人构造的可解/不可解）与**外部计量**（代理处逐字记录的 usage）上，写不动。

### 2.2 主终点 B · 判决题准确率（含特异度）

**出题**：三类变体，逐类若干题（题数进 PENDING_FIVE 的 ⟨m⟩）：
(i) 小空间不可解、(ii) 大空间不可解、(iii) 可解但难。真值来自**构造**——每个变体随附
构造性依据（Theoria.md Phase 1 变体注入层），不靠跑来确认。

**答案**：每题强制三选一 —— `unsolvable` / `solvable` / `no-answer`。超时或超预算
自动计 `no-answer`。

**计分**：

```
sensitivity = 正确答 unsolvable 的不可解题数 / 不可解题总数     （类 i + ii）
specificity = 正确答 solvable  的可解题数   / 可解题总数        （类 iii）
balanced accuracy = (sensitivity + specificity) / 2
```

**`no-answer` 在两边都计错。** 这条是刻意的，理由是三个反例：

* 只会喊 `unsolvable` 的臂：sensitivity 1、specificity 0 → **0.5**；
* 只会喊 `solvable` 的臂：**0.5**；
* 一律弃权的臂：**0**。

于是无信息策略的天花板是 0.5，弃权不再是躲避特异度惩罚的免费出口。若把弃权算作「不是
假阳性」，弃权就会变成最优策略，而 Theoria.md 1.11 要的恰恰相反：「敢说不可解的框架
必须在这里闭嘴」——闭嘴指的是在**可解**题上不喊不可解，不是在所有题上不作声。

**主终点取的是每局的 balanced accuracy**（各臂在同一批题上答，逐局配对）。
弃权率逐臂逐类另行报告，**不参与主检验**。

#### 2.2.1 一个必须当场判掉的争议：证书算不算分

Theoria.md 1.11 (i) 说得很清楚：小空间不可解题上，连 Schema 的完备搜索都会正确地停，
**甚至可能因漏边而以错误的理由得到正确的判决**，「所以这里考的是理由：证书，还是
『我搜过了没有』」。

**裁决：主终点只看判决，不看理由。** 理由是循环性——只有本框架产出机器可查的证书，
把证书写进主终点等于把主终点定义成「谁像 Theoria」，评审第一句话就会是这个。

**同时预注册一个次终点（探索性，不参与 Holm 族）**：

```
certified rate = 带机器可查证书的正确 unsolvable 判决数 / 正确 unsolvable 判决数
```

它对 Schema 与裸 CC 恒为 0（他们没有这件交付物），所以它**不是对照量，是描述量**——
论文里必须以「这是交付物差异，不是性能差异」的措辞出现。这一条现在写死，免得结果出来
之后有人把它读成主张。

### 2.3 主终点 C · 前载指数配对差

**成本**：模型代理处逐字记录的 provider usage，按冻结价目表换算（Theoria.md Phase 1
第 3 层：「成本是换算不是记录」）。引擎调用与脚本执行**不计**（约束 8）。

**前载指数**：

```
FLI_k = 前 k% 回合花掉的成本 / 该局总成本
```

`k` 是待定五项之一（PENDING_FIVE，建议值见该文件）。**k 只有一个值进主终点**；
其余 k 的曲线是探索性材料。

**整全性条件（integrity condition）**：某局某臂的回合数 < ⟨T_min⟩ 时，FLI 退化
（两回合的局，FLI 只能取几个离散值），该格按 §1.4 计为缺格。`T_min` 进 PENDING_FIVE。

**主终点量** = 逐局的 `FLI_k(Theoria) − FLI_k(对照臂)`。

**一条必须一起报的话**：FLI 高既可能来自「早期在做科学、后期懂了」，也可能来自
「第一回合灌了一次巨型上下文」。所以 FLI **必须与总成本、收敛点一起报告**，且
预注册：**总成本显著更高时，C2 不得被主张为「理解的签名」**，只能报为「前载但更贵」
——Theoria.md 1.6 已经给这个结局留了座（「理解的价格」）。

## 3. 检验方法：按数据类型钉死，不留选择

| 主终点 | 每局的量 | 检验 | 为什么是它 |
|---|---|---|---|
| A · U3 达成率 | 二值 | **精确 McNemar（= 配对符号检验）**，只看不一致对 | 配对二值数据的正确检验；配对的 t / 卡方在这里都是错的 |
| B · 判决题平衡准确率 | [0,1] 连续 | **Wilcoxon 符号秩** | 配对、不假定正态、局数小 |
| C · 前载指数配对差 | [0,1] 连续 | **Wilcoxon 符号秩** | 同上 |

**零差异（ties）用 Pratt 法处理**：零差异**保留**并参与定秩，而不是 Wilcoxon 原始做法
里的丢弃。丢弃零差异会在平局多的时候**高估**显著性，而本实验平局不会少（U3 上尤其）。
Pratt 在我们这个方向上是保守的，所以选它。

**双侧，α = 0.05。** 尽管方向预测已在 Phase 2 预注册，主检验仍取双侧：单侧检验在
「结果反过来了」的情形下没有位置，而 [CLAIMS_TEXT.md](CLAIMS_TEXT.md) 的双结局文本
必须能承接那个情形。**反方向的显著结果按「主张被证伪」处理**，不按「未达显著」处理。

**多重比较**：三个主终点构成一个族，用 **Holm–Bonferroni** 控制族错误率 0.05。
（不用 Bonferroni：Holm 在同样的 FWER 下一致更有力，且同样可以逐字预注册。）
电池其余指标一律**探索性**，报名义 p 值，明确标注不参与确证，不做校正也不作主张——
这正是 Theoria.md「免多重比较稀释」那句的落法。

**效应量与区间**：每个主终点同时报配对差的中位数与 Hodges–Lehmann 估计 + 95% 分布
自由区间；**p 值不单独出现在摘要里**。

**精确检验，不用正态近似**：局数在 20 上下，正态近似不可靠；三个检验都取精确版本
（McNemar 二项精确；Wilcoxon 精确零分布，平局时用 Pratt 的精确枚举，枚举不动时报
明确的近似方法与理由）。

## 4. 对照臂：主检验只对一条，消融臂用门槛而不是 p 值

**主检验的对照臂 = Schema（复现口径）。** 三个主终点各只对这一条对照做一次检验，
族大小因此正好是 3。

**裸 CC 与消融臂怎么处理**：

* **裸 CC**：全部对照量报为描述性，不进 Holm 族。理由：42.83% 与 98.98% 的差距不是
  本文要争的东西，Schema 才是天花板。
* **消融臂（Theoria − 定理义务）**：Theoria.md 称它为「活命臂」，因为评审第一拳是
  「你只是发了 diff」。但把它也塞进假设检验会让族大小翻倍、把功效摊薄。
  **裁决：消融臂做成 C1 的「门槛条件」而不是第四、五、六个检验**——

  > C1 只在**消融臂的 U3 达成率 ≤ ⟨g⟩**时被主张；否则 C1 判为「不被支持」，无论
  > Theoria 对 Schema 的检验结果如何。

  `g` 进 PENDING_FIVE（建议 0）。这是一条**只会削弱本方主张、不会加强它**的规则，
  所以它可以安全地预注册。

  **照录一条限制**：门槛条件不是显著性检验，它不带 p 值，也不能反过来当成
  「消融臂显著更差」的证据。论文里必须以门槛的措辞出现。

## 6. ⟨n⟩ 怎么定：把规则写死，值留给 PENDING_FIVE

Theoria.md：「⟨n⟩ 由开发堆方差在冻结前定：方差小则 n=1 可辩护，否则 n=2」。

**判据（本文件的贡献是把「方差小」变成一个可执行的门）**：

> 取开发堆上已有的对照两臂逐格重复数据，对每个主终点算**格内**离散度。
> 若**所有**主终点上，格内离散度都满足下表，则 **n = 1**；否则 **n = 2**。

| 主终点 | 格内离散度判据 | 门槛 |
|---|---|---|
| A · U3（二值） | 同格 n 次的判定是否一致 | **全部一致**才算小 |
| B · 平衡准确率 | 同格极差 | ≤ **0.10** |
| C · 前载指数 | 同格极差 | ≤ **0.10** |

**为什么是极差而不是标准差**：开发堆每格重复次数是 2–3，这个样本量上的标准差估计
本身噪声比信号大；极差是同样信息下更诚实的读法。

**为什么门槛是 0.10**：它是主终点量程（[0,1]）的十分之一，也是我们愿意被单次重复的
偶然性推动的上限。这个数是**判断**，不是推导——写在这里就是为了让它接受审视，而不是
藏在结果里。

**若开发堆数据不足以算出这三个离散度**（例如对照臂在开发堆上没有重复跑，或
`ar25 degraded` 一类的降级把某些格作废），则**默认 n = 2**，并在冻结说明里写明是
「数据不足，取保守值」而不是「方差大」。两者是不同的事实，不许混着说。

**`ar25 degraded` 的敏感性处理（预注册）**：凡被标记 degraded 的格，主分析**剔除**
（按 §1.4 计缺格）；同时做一次**敏感性分析**，把 degraded 格按其记录值纳入，
两套结果**并排报告**。若两套结果的定性结论不同（某主终点在一套里显著、另一套里不
显著），则该终点判为**不稳健**，主张降级为「方向一致但不稳健」。

## 7. 这份规则的已知薄弱处（先自己说）

1. **功效没有事前计算。** 局数由封存堆大小决定（21 局，扣除 F-11 隔离后 19），不是
   由功效分析决定；n 也由方差而非功效定。所以「未达显著」在本实验里**不能**读成
   「无差异」，双结局文本已按此措辞。真正的事前功效计算需要效应量先验，而我们没有。
2. **U3 的非空转条款堵不住「真但无聊」。** §2.1.1 末尾已照录。
3. **三个主终点不是独立的。** U3 达成与判决题准确率都吃「证得动」这件事，Holm 假定的
   是最坏情形依赖，所以校正**偏保守**——这一次保守的方向对本方不利，如实报。
4. **配对检验吃的是局间难度差，吃不掉臂间的实现成熟度差。** Theoria 臂是本项目自己
   写的，Schema 是复现的；实现成熟度不是随机化能消掉的东西。这条限制进论文局限节，
   不假装被统计设计解决了。
5. **`no-answer` 计错的代价**：一个把「不确定」如实说出来的臂，在本规则下拿到的分数
   低于一个乱猜的臂（乱猜期望 0.5，全弃权 0）。这是为了堵死弃权套利而付的价，代价
   照录。
