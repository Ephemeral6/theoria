Theoria.md:299 本来就把**动画**与**内部 tick** 并列为同一观测的**两个**候选成因，
只说 API 的答案解决作业的**一半**；Theoria.md:301 随后把它压成一个三段论

读者看到的都是**一个挂着观测证据的结论**。

分开它们需要的不是更多帧，而是**另一种测量**：逐帧哈希（P-20 做了），以及
「中间帧是不是一个规则**能从它开火**的状态」（P-20 自己在末尾点名说没做，称之为
「级联语义留下的下一个真问题」）。最终裁决执行了那句话。

**裁决**：渲染爆发，不是 tick。`step` 冻结为 `S → A → frames[-1]`；四个开发局
`cascade single_frame`；`theory.pddl` **不需要** derived predicates；
`cold-start-a0` 的 **D-A0-004 无需修订**——`cascade` 是逐世界的事实，A0 与
ARC-AGI-3 是两个世界，两份声明从来不冲突，冲突的表象来自把 API 的帧**列表**读成
关于 A0 **规则**的陈述。engine-rig 侧的 T-11c 在 47,040 个 (state, action) 对上
独立得出同一结论，判据也相同。**两条轨道一直是一致的；需要裁决的是 ARC 这一侧。**

裁决带着**可反驳条件**，而且是 Phase 3 的**必做项**而非脚注：每次预测与观测不符时，
记录「反复重放到静止是否就能预测出该观测」。这个计数器只要非零，该世界的 `cascade`
就是 `multi_frame`，裁决作废。三个明说的缺口：G-1 判据从未被直接跑过；G-2 所有轨迹
