## 头号发现

`Theoria.md:271` 那一列里唯一自称「实测」的格子——`~10⁸(实测 2.04–3.41 亿)`——
**测不出来，而且此前从未被测过**。`AUDIT.md` §1.2 在开工时把整行登记为占位符，
但登记的对象是 `⟨复现值⟩`，「实测 2.04–3.41 亿」被一路带了过去，
从此以一个有出处的数的样子存在了四天。

本轮第一次去数：

* 去重口径（按 `message.id`，只取顶层 `usage`）：**0.756–2.85 亿**，4 个 run；
* 朴素树遍历（把 `usage.iterations[*]` 里的重复计数也加进去）：**3.19–13.19 亿**；
* 表里的 **2.04–3.41 亿** 落在两者之间，**任一口径都不产生它**。

数量级 `~10⁸` 站得住，括号里的区间站不住。

## 三件事被同时看清

1. **半条臂没有 token。** 8 个 run 中 4 个（整个 `gpt_5_6_sol` 采集）
   一个 token 字段都没有，所以这一格实际靠 25 局中的 4 局 × 2 套采集中的 1 套。
   反讽的是 codex 那半边的 ARC 动作更多（2,595 vs 1,466）。
2. **路 (a) 的钱第一次被算出来。** 按 `proxy/pricing/pricing_v1.json`
   给已测的 4 局计价 **$649.80**，外推 25 局 **$4,061**，池中 **$143.50**，
   **差 28.3 倍**。而动作反而够（9,163 / 15,845 = 58%）——
   **钱先于动作成为墙，与 Phase 1 的预判相反。**
3. **三处对同一批材料有三种说法**：臂名 `schema_repro` 说它是复现；
   `freeze/CLAIMS_TEXT.md:23` 说它不存在；论文 §7.2 说它存在但不是复现。
   第三种是对的，前两种是 D-B-019 那次混淆的残留物。
