## 0. 判据

### 0.1 「仍与当前指标定义对应」

**N**（名）标识符在 `battery/metrics/` 找得到或改名有据；**D**（口径）计算规则自
预测写下后未变；**A**（臂）预测点名的臂今天仍指同一构念。三项全过记 `对应`。

### 0.2 「顺序」

`git merge-base --is-ancestor <预注册> <首次回算>`，退出码 0 且反向非 0 = 严格成立。
查不出的写「无法确定先后，因为 X」，不猜。第二层是**预注册当时已看见的值**，
git 证不了，靠封条声明加事后可查证据。

### 0.3 「足够具体到能被证伪」—— 四条，F4 是对抗复核加的

* **F1** 预测点名的量由已注册指标算得出；

* **F3** 该量在预测所述的臂上能算出 `ok`；只能得到 `no-data`/`not-applicable` 的记
  `当前材料不可判定`；
* **F4（新增，对抗复核 §3.4）** **不存在一个明显不具备该能力的臂能使预测成立。**

**F4 是第 1 版漏掉的那一条，而它是这道工序真正要防的东西。** 对抗复核对我夸为
