### 3. 新增：`.env` 里那把 key 挂在哪个 ARC 账户下？

第三轮实查发现，已登录账户面板里唯一那把 key 是 `a4***a91b`（创建于 2026-07-28 11:48），
而本仓 `.env` 的 `ARC_API_KEY` 在同一打码口径下是 `71***05dd`
（用 `arc-recon/client.py` 的 `mask()` 比对，**全程未打印明文**）。**不是同一把。**
旁证：该账户 `/platform/scorecards` 列表为空，而 `baseline-arms` 今天已开过并关过记分卡。

* **最可能的解释**：ARC 有 Google 与 GitHub 两个独立登录入口，
  同一邮箱走不同入口会落到两个账户上；`.env` 那把大概率属于另一个。
* **要人做什么**：在同一浏览器里换另一个入口登录，看面板里的 key 首两位是不是 `71`。
* **在那之前的工作假设**：**我们无法吊销或轮换 `.env` 里那把 key。**
  它是活的（今天的战役与预检都在用），所以这不是失效问题，是"不知道谁能管它"的问题。
* **不影响本次核查的结论**：面板里本来就没有 per-key 的配额或权限可看，
  换成正确账户也读不出更多东西。
